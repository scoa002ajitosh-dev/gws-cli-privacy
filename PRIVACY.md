# Privacy Policy — GWS CLI

Last updated: 27 September 2026

## Scope

GWS CLI is a private command-line tool. Its owner operates it for personal use
only. The tool is not offered to the public, and it has no other users.

## Data the app accesses

After you grant consent, the app can access the Google account data that you
authorize. This can include Gmail, Google Drive, Google Calendar, Contacts, and
the other Google APIs shown on the consent screen.

## How the app uses the data

The app uses the data only to carry out tasks that the owner requests. Examples
are listing and copying files in Google Drive, reading and sending the owner's
own mail, and reading the owner's own calendar.

The app does not use the data for advertising, profiling, or resale.

## Where the data is stored

OAuth tokens are stored as files on the owner's own computer. The operating
system file permissions and the system keychain protect them. The app keeps no
server-side copy of your data.

## Sharing

The app shares no Google user data with any third party. It does not sell Google
user data.

## Retention and deletion

Tokens stay until the owner revokes access. To revoke access, open
https://myaccount.google.com/permissions and remove access for GWS CLI. The
owner can also delete the local token files.

After revocation the app cannot reach the account.

## Google API Services User Data Policy

The use of information received from Google APIs by GWS CLI adheres to the
Google API Services User Data Policy, including the Limited Use requirements.
